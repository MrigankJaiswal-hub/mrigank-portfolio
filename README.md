# Mrigank Jaiswal · Engineering Portfolio

Mrigank Jaiswal's personal engineering portfolio for the AWS Student Builder Challenge.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript.

Beam Lab computes and plots the normalized array factor of an idealized four-element linear antenna array with half-wavelength spacing. Move the steering slider with a mouse, touch, or arrow keys to explore the pattern and reveal how it connects to the fixed-point beamforming project.

## Deploy on AWS Amplify Hosting

1. Create a new public GitHub repository and upload the contents of this folder to its root.
2. In AWS Amplify Hosting, create an app from GitHub and select the repository and branch. Keep the app root at the repository root and use the included `amplify.yml` build settings.
3. Deploy and open the generated Amplify URL in a private browser window. Check section links, GitHub and LinkedIn, mobile layout, and the arcade controls.
4. Capture the live portfolio, the completed simulation, and the successful deployment in Amplify. Submit the public site and repo URLs, screenshots, and your own notes about the build under **Your project** on AWS Builder Center.

The portfolio's AWS service is Amplify Hosting after deployment. The simulator runs in the browser and uses illustrative data.

## Portrait, logos, and games

The supplied portrait and available logo assets are bundled under `assets/`. Click the hero portrait to cycle its lighting. If you add an approved illustrated portrait later, use the class `portrait-photo portrait-photo--illustrated` so the hero button can switch between both images.

The arcade includes mate-in-one chess puzzles, Packet Snake, Signal Lock, and Bit Match. All four run offline in the browser.

## Browse the cards

Use **View details** to flip a card and **Back to overview** to return. The reverse can contain repository, badge, or article links. The project filters apply to the illustrated project cards, while the expandable repository list stays available below.
